# Base de Conhecimento da SIA

Esta pasta contém os arquivos utilizados pela SIA para responder perguntas sobre educação financeira.

## Arquivos

- conceitos_financeiros.json → Conceitos fundamentais de finanças pessoais.
- perfil_investidor.json → Características dos perfis de investidor.
- produtos_financeiros.json → Informações sobre os principais produtos financeiros.
- perguntas_frequentes.json → Perguntas e respostas comuns.
- dicas_financeiras.json → Recomendações gerais de educação financeira.

Todas as informações foram estruturadas a partir de fontes oficiais e materiais de educação financeira, visando facilitar futuras integrações com o SmartWallet.
